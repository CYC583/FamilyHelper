# 測試與實機驗收

自動化測試涵蓋純狀態邏輯、資料庫規則、Callable Functions 與 Flutter widget。手機硬體相關行為（螢幕分享、無障礙、推播、省電）只能在實機驗收，下方清單是建議的驗收項目，**不是已完成的測試報告**。

## 可重複執行的命令

```bash
python3 tool/check_sources.py
python3 -m unittest discover -s tool/tests -p 'test_*.py'
cd backend/functions
npm ci
npm test
cd ..
npx --yes firebase-tools@15.26.0 emulators:exec --only database --project demo-familyhelper 'cd functions && npm run test:rules'
cd ..
flutter pub get
flutter analyze
flutter test
```

Windows 可用 PowerShell 執行；外層命令的引號依終端機調整。Rules 測試只接受 localhost／127.0.0.1 Emulator，拒絕正式資料庫；測試會清空**模擬器的測試資料**。

CI workflow 會編譯兩個未配置的 debug APK，檢查原生程式及 manifest；那不是可用的正式安裝包。正式安裝包請用 `python3 tool/setup.py` 或 `python3 tool/build_apks.py` 產生。

## 配對與授權

- [ ] 同一碼被第一台用過後，第二台不能再用；重發新碼後可以。
- [ ] 未配對手機不能讀取家庭／健康／信令。
- [ ] 第二到第六台各用新碼成功；第七台被拒絕；解除一台後第七台可以重新配對。
- [ ] 錯碼限流後，重開 App 不會解除後端限流。
- [ ] 多位 client 中任兩位同時請求，只有一個取得協助位置，另一個顯示忙碌。
- [ ] 長輩拒絕、未回應逾時、取消相機或麥克風、取消螢幕分享：不建立連線，釋放位置。
- [ ] client 修改本地 UI 或直接寫 accepted，資料庫規則拒絕。
- [ ] 長輩解除正在協助的 client，控制與信令立即失效。

## 影音、畫面與操控

- [ ] 雙方互相聽得到、看得到；戴耳機檢查回音。
- [ ] client 明確分開螢幕、長輩相機與自己的預覽，不把相機當成待點擊螢幕。
- [ ] 長輩手機直向／橫向切換後，畫面比例與點擊位置一致。
- [ ] 點黑邊無動作；過期畫面尺寸、NaN、超範圍座標、舊序號均拒絕。
- [ ] 單點、長按、滑動可用；多指操作不誤觸。
- [ ] 系統權限／設定／安裝畫面及 FamilyHelper 自己不能被遠端點擊。
- [ ] host 沒開無障礙時仍可視訊與看畫面，client 顯示僅觀看。
- [ ] 傳送大字訊息：host 前景顯示大字、背景顯示通知；不會擅自跳到前景。

## 停止與資源回收（關鍵）

- [ ] host 按結束或分享通知的停止，不能再點擊，螢幕分享與相機／麥克風都關閉。
- [ ] client 結束或 Android 返回鍵，雙方均結束。
- [ ] Android 分享控制列按停止；修補的 native onStop 會清除控制。
- [ ] host 鎖屏立即取消控制；解鎖後需新請求與新同意，不自動恢復。
- [ ] 關 Wi-Fi、切飛航、路由器斷電，連線停止；另一個家人可在租約失效後再請求。
- [ ] 反覆連線／結束不殘留相機占用、前台分享通知、DataChannel 或同意狀態。
- [ ] 同意後在系統授權畫面拖很久，逾時後不能憑舊同意重新啟動。
- [ ] 拒絕後立刻接受新請求，舊擷取的停止回呼不會影響新連線。

## SOS、推播與 Widget

- [ ] App 前景、背景、被滑掉時各測一次通知；**強制停止後不應承諾可送達**。
- [ ] host 從桌面兩種 Widget 冷啟動，送出對應 SOS／呼叫一次。
- [ ] client 各收到推播，開啟能查看資料庫保存的通知。
- [ ] 位置允許／拒絕／GPS 關閉／取不到位置，各有正確結果。
- [ ] 顯示推播「已送出請求」和家人「確認收到」的差異，不把推播 API 成功等同人已收到。
- [ ] 沒有網路／沒有已綁定家人，host 顯示失敗，不能顯示求助成功。
- [ ] App 的通知被關閉時，家人能理解該限制；確認各廠牌的電池最佳化設定。

## 跨網路／TURN

- [ ] 同 Wi-Fi。
- [ ] 長輩 Wi-Fi，你用行動網路。
- [ ] 兩邊不同 Wi-Fi。
- [ ] 測試版強制 relay，驗證 TURN UDP 和 TCP/TLS；恢復原設定。
- [ ] TURN 憑證過期／錯誤時顯示失敗，不悄悄宣稱連線成功。

## 健康（選用）

- [ ] 沒有 Health Connect，主功能仍正常。
- [ ] 預設關閉，不先行要求健康權限。
- [ ] Samsung Health 已同步後，能看到心率、血氧、睡眠區間的數值及原始記錄時間。
- [ ] 沒有來源資料顯示沒有資料，不拿預設數字補上。
- [ ] 舊數值不觸發即時提醒；新數值依自訂閾值提醒；同一筆不連續發送。
- [ ] 關閉 health 後停止同步，清除雲端最新資料；系統撤銷權限後讀取失敗可辨識。
- [ ] App 不在前景時，本版不承諾持續監測。
